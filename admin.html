How do I get an admin key?
  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: mcrangers. Repository access: Only select repositories → hike-bingo.
  3. Permissions → Repository → Contents: Read and write.
  4. Pick an expiry (e.g. 30 days), generate, and paste the key here. It's saved only on this device.
